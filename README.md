# Receipts — наши рецепты и что есть дома

Веб-приложение (PWA) на двоих: коллекция рецептов, позже — сток продуктов.
База и вход — Supabase, хостинг — GitHub Pages.

## Структура
- `supabase/schema.sql` — таблицы и права доступа. Выполняется один раз.
- `supabase/seed_batch01.sql` — первые 20 рецептов из Телеграм-чата. Можно выполнять повторно: старые копии заменяются.
- `supabase/add_member.sql` — добавить человека в дом.
- `import/` — разбор рецептов: `batchNN.py` → `batchNN.json` → `to_sql.py` → SQL; `preview.py` — HTML-превью карточек.

## Правила карточек
- Название ингредиента начинается с категории: «сыр тильзитер», а не «тильзитер».
- Категория для поиска и стока (`base`) — внутреннее поле, в карточке не показывается.
- Взаимозаменяемые ингредиенты — одна строка через «или» (`alt_group`).
- Оригинальная формулировка — в `raw`, пересчёт ложек в граммы — в `grams` с пометкой ≈.
